# 学习通作业抓取工具 · 使用帮助

欢迎使用！这篇文章会**手把手**带你把学习通（超星）里的作业**一键抓下来，保存成 Word 文档**。就算你完全不懂电脑，照着每一步做就能搞定。

> 本软件是 macOS 原生应用，界面为 SwiftUI；底层自动调用内置的浏览器引擎（Python + Playwright）完成抓取，**不需要你在电脑上安装任何额外软件**。

## 一、这个软件是干什么的？

简单说：**把学习通网页上的作业题目、选项、图片、参考答案，自动保存成一份 Word 文档**，方便你离线查看、打印或交给他人。

它帮你自动完成三件麻烦事：
- **自动翻页**：作业很多页也不用手动翻，它会一页页把题目都抓下来。
- **下载图片**：题目或选项里带的图片，会自动下载到本地放进文档，不会变成“红叉”。
- **合并文件**：一次勾选的多个作业，会全部合并进**同一个** Word 文档，不用自己手动复制粘贴。

## 二、安装与打开（已装好可直接跳过）

你既然能看到这份帮助，说明软件已经**成功装好并打开了**，安装的部分这里就一笔带过，只提醒你两件可能会遇到的小事：

- **第一次打开会问你要通知权限**：点「允许 / 好」即可。就算不点，抓取功能也完全正常，只是抓完不会弹提醒。
- **如果系统提示“无法打开，因为来自身份不明的开发者”**：在「应用程序」里**右键**点 App 图标 → 选「打开」→ 再点一次「打开」。就这一次，之后双击就能直接开了。

> 已经能正常看到主界面的话，别管上面这些，直接进入下一步**登录**就行。

## 三、登录学习通（扫一扫就行）

软件的登录方式很简单：**用手机上的“学习通”App 扫一扫**。

1. 打开软件，如果还没登录，会弹出登录窗口，中间显示一个**二维码**。
2. 打开手机上的 **学习通 App** → 右上角「扫一扫」→ 对准电脑屏幕上的二维码。
3. 手机里确认登录后，电脑端会自动跳转。如果二维码过期了，它会**自动刷新**，直接扫新的就行。
4. 只有二维码没自动跳转时，才需要点击「已完成登录，继续」。

> 登录成功后，登录状态会自动保存，**下次打开不用再扫**。只有登录失效（长时间不用或换账号）才需要重新扫一次。

## 四、三步抓取作业

登录后，主界面会带你走三个步骤，每一步都有清晰的按钮，照着点即可。

### 第 1 步：选择课程

1. 点击 **「选择课程」** 下拉菜单，会列出你在学习通账号里的所有课程。
2. 点选**要抓取的课程**。
3. 如果列表里没有你的课程，可以展开下方的课程 URL 输入框，粘贴**课程页面的网址**（在浏览器里打开该课程后，复制地址栏链接即可）作为兜底。

> - 课程封面会自动显示真实缩略图；“课程已结束”的课程会排在最后面，并显示灰色遮罩提示。
> - 已经登录的话，软件会在后台提前把课程加载好，进入时不需等待。

### 第 2 步：勾选作业

1. 选中课程后，软件会自动加载该课程的作业列表。
2. 列表里每个作业前面都有一个**勾选框**，点一下即可选中。
3. 想全部要？点列表上方或菜单的 **Command（⌘）+ A** 全选；想清空点 **Command（⌘）+ Shift（⇧）+ A**。

### 第 3 步：开始抓取

1. 勾好作业后，点击 **「开始抓取」** 按钮。
2. 软件会自动打开内置浏览器，逐项抓取。你可以在右侧看到**实时进度条和日志**。
3. **抓取过程中也可以继续勾选新作业**，新勾的会自动追加进队列，不用停下来重开。
4. 每个作业右侧会实时显示状态：**进行中 / ✓ 完成 / ✗ 失败**。
5. 全部完成后会弹出完成提示、播放提示音，并（可选）自动打开结果文件夹。

> 想中途停？点「停止」按钮——为防止误点，要**连点两次**（第一次变成「确认停止」，10 秒内再点一次才真正停止）。

## 五、抓取完的结果在哪里

抓取结果默认保存在 **`~/Desktop/out`**（也就是电脑桌面上的 `out` 文件夹），你会在里面看到：

```
out/
  └── 课程名称_时间/        ← 本次运行的结果文件夹
        ├── images/         ← 下载的图片（按作业分文件夹）
        ├── 作业1.docx      ← 每个作业一个 Word 文件
        ├── 作业2.docx
        └── 合并文档.docx    ← 所有抓取作业合并成的一份
```

- `.docx` 就是 Word 文档，双击用 Word / Pages / WPS 打开。
- 如果在设置里开了「自动导出 PDF」，还会生成对应的 PDF 文件。
- `debug/` 文件夹存放调试日志，方便排查问题，一般不用管。

## 六、设置项 —— 大白话讲解

在菜单栏点 **「XxtApp」→「设置…」**（或按 **Command（⌘）+ ,**），可看到以下选项：

| 设置项 | 大白话说明 |
| --- | --- |
| **输出目录** | 抓取结果保存到哪里。默认桌面 `out` 文件夹，可改成自己喜欢的文件夹。 |
| **自动导出 PDF** | 保存 Word 后，顺便再导出一份 PDF 格式（打印更方便）。 |
| **强制重新抓取已完成** | 默认“已抓过的会跳过（断点续传）”。打开这个开关后，每次全部重新抓一遍。 |
| **完成时自动打开输出目录** | 抓完后自动弹出文件夹窗口给你看结果。 |
| **完成时播放提示音 / 发送系统通知** | 抓完有没有“叮”一声 + 弹系统通知提醒你。 |
| **展示来源 URL** | 是否在文档标题下方标出“来源：网页链接”。 |
| **登录 / 退出登录** | 这里可以看当前登录状态：未登录点「登录学习通」；已登录点「退出登录」清除登录状态。 |
| **存储空间** | 统计结果文件夹占了多少空间（Word / 图片 / PDF / 其他），可一键清理（会有二次确认，放心点）。 |

> 设置会自动保存，下次打开还是你设好的样子。

## 八、常见问题与故障排查

**Q1：开始抓取后，右上角提示“URL 中的 enc/t 参数已过期”？**
这是学习通的链接有时效性。请重新在浏览器打开课程页，复制**最新**的网址粘贴进来再试。

**Q2：选中课程后作业列表是空的 / 找不到作业？**
确认课程链接正确、你确实在这个班级里；稍等刷新，或换一门课试一下。

**Q3：有些题的答案没抓到？**
答案受“页面是否已作答”影响。如果该题你还没作答，可能看不到参考答案——先手动作答，再重抓该作业即可。

**Q4：抓到一半想停下来怎么办？**
点「停止」按钮连点两次（或按 `⌘.`）。已经抓完的部分都已保存到硬盘，下次可继续，不会白抓。

**Q5：`.docx` 文件双击打不开？**
需要电脑上装了支持 Office 格式的软件，如 **Microsoft Word、Pages 或 WPS**。

**Q6：图片好像丢了？**
图片在 `结果文件夹/images/作业标题/` 里。某作业本来就没有图的话，那个空子文件夹会自动被清理，属正常现象。

**Q7：输出文件夹里找不到，怎么去？**
按 `⌘O`，或在设置里看「输出目录」设到了哪，按该路径去访达找。

**Q8：软件被系统拦截“身份不明开发者”？**
见上文[安装与打开](#二安装与打开已装好可直接跳过)，在“应用程序”里右键 → 打开 → 打开 即可。

**Q9：看完这段还不够，界面和说明书对不上？**
本帮助会随版本持续更新，个别细节以软件当前界面为准。

## 九、给开发者的说明

- 底部依赖 Python 引擎（源码在与 `xxt-swift` 同级的工程根目录：`bridge.py` + `core/` + `spider/` + `exporters/`）与 Playwright。
- 引擎侧改动（`core/`、`spider/` 等 `.py`）需先 `./script/build_engine.sh` 重打包引擎，再进 App。
- 仅改动 SwiftGUI 侧才只需 `./xxt-swift/script/build_and_run.sh`。

```bash
cd <你的工程根目录（含 bridge.py）>
./script/build_engine.sh                     # 只改 Python 引擎时执行
cd xxt-swift
./script/build_and_run.sh                    # 构建 → 签名 → 启动
```

### v2.3 beta · 稳定性与修复版（当前版本）
- **修复公式/符号抓取异常**：之前带数学公式的题目（如组合数公式）抓取后部分符号会变成“?”，现已修复——剔除学习通服务端塞进页面的“隐形无障碍层”（内部为损坏乱码字符），保证公式文本完整正常
