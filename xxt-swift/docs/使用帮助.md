# 学习通作业抓取工具 · 使用帮助

一个 macOS 原生应用，用于抓取学习通（超星）课程作业并保存为 Word 文档。界面为 SwiftUI 原生实现，底层复用 Python / Playwright 引擎。

---

## 一、功能简介

- **抓取作业**：自动进入课程作业/测验列表，逐题抓取题目与选项内容，保存为 Word（.docx）。
- **识别答案**：展开作答区域后的参考答案一并抓取（受页面是否已作答影响）。
- **图片下载**：题目与选项中的图片会下载到本地并以相对路径引用。
- **多作业合并**：一次运行抓到的所有作业合并进同一个 Word 文档。
- **断点续传**：通过 `progress.json` 记录作业状态，已完成的作业下次自动跳过。
- **自动导出 PDF**：可选择保存 Word 后自动转出 PDF。
- **自动打开目录**：可在抓取全部完成后自动在 Finder 中打开本次输出目录。

## 二、首次运行与登录

1. 双击 `/xxt-swift/dist/XxtApp.app` 启动（或运行 `build_and_run.sh`）。
2. 若未登录学习通，应用会弹出登录界面并**原生显示二维码**。
3. 用**学习通 App 扫码**，然后点击“已完成登录，继续”（二维码过期会自动刷新）。
4. 登录成功后登录态自动保存并复用，无需反复登录。

> 说明：登录状态保存在 `state.json`。若凭据过期失效，删除该文件或重新扫码登录即可。

## 三、抓取作业流程

1. 确认**课程链接**（URL）正确 —— 在设置或侧栏输入框填入课程页链接。
2. 在左侧作业列表**勾选要抓取的作业**（默认全部）。
3. 点击“开始抓取”，应用会启动浏览器引擎并逐项抓取。
4. 右侧日志区实时显示进度；侧栏每个作业显示抓取状态（进行中 / ✓完成 / ✗失败）。
5. 抓取完成后在输出目录生成 `/课程名称_YYYYMMDD_HHMMSS/` 文件夹，内含各作业的 Word 与合并文档。

### 常见报错

- **提示 URL 中 enc/t 参数已过期** → 重新打开课程页复制最新链接填入。
- **作业列表为空 / 找不到作业** → 确认课程链接正确且已进入对应班级。
- **答案未识别** → 该题可能未作答，或题目在 iframe 内需要重新定位；可手动作答后重试。

## 四、设置项说明

打开菜单栏「**学习通作业抓取 → 设置…**」（或 `⌘,`）：

| 设置项 | 说明 |
| --- | --- |
| 输出目录 | 抓取结果的保存位置，默认为 `~/Downloads` |
| 课程链接 | 学习通课程页 URL（含 enc/t 参数） |
| 显示浏览器 | 仅在需要可视化浏览器会话时开启（会触发完整 Chromium 按需下载）；默认关闭的无头模式即可完成扫码登录与抓取 |
| 保存后自动导出 PDF | 是否在保存 Word 后同时导出 PDF |
| 强制重新抓取已完成的作业 | 取消断点续传，重新抓取全部 |
| **抓取完成后自动打开输出目录** | 全部抓取结束后自动在 Finder 打开结果目录 |

设置会保存到 `settings.json`，下次启动自动加载。

## 六、常见问题（FAQ）

**Q：`.docx` 打不开？**
需安装 Microsoft Word 或 Pages / WPS 等支持 Office 格式的软件。

**Q：抓取到一半想中断？**
点击菜单栏「操作 → 停止任务」（`⌘.`），已完成的部分已落盘，可从断点继续。

**Q：输出的图片丢了？**
图片保存在 `/输出目录/日期文件夹/images/作业标题/`。若某作业没有图片，该子目录会自动清理。

**Q：如何从启动台找到应用？**
应用位于自定义目录，启动台不会自动收录。需将 `XxtApp.app` 手动拖入 `/Applications`。
