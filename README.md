# 学习通作业爬取工具

> **⚠️ 仅支持 macOS**：本工具为 **macOS 原生应用**（SwiftUI），仅适配 macOS，不提供 Windows / Linux 版本。

一个 macOS 原生（SwiftUI）图形化工具，用于批量抓取学习通（超星）课程作业的题目、选项与答案，并导出为 Word / PDF 文档。

> **声明**：本工具仅供个人备份已购买的课程内容使用，请勿用于侵犯他人权益或违反平台规则的用途。

---

## 功能特性

- 图形界面操作，无需记忆命令行
- 自动登录态持久化，一次登录后续复用；已登录启动即静默预加载课程列表
- **选择课程**：从账号课程下拉选择即可直接加载作业（课程 URL 输入保留作兜底）
- 自动进入课程作业列表，批量抓取每个作业
- 自动过滤“智能分析”页面，避免误入统计页
- 支持题目分页、逐题翻页
- 支持文字、图片题干与选项
- 图片自动下载到本地并嵌入 Word
- 自动合并本次所有作业为一个 Word 文档
- 可选自动导出 PDF
- **抓取中动态入队**：运行中可继续勾选新增作业，自动追加进当前队列
- **课程卡片体验**：真实封面缩略图；「课程已结束」课程自动置底并加遮罩标记
- 支持历史作业批量修复（重新抓取答案缺失的作业）
- macOS 原生界面（SwiftUI），流畅的中文体验

## 系统要求

- **macOS 14.0（Sonoma）或更高版本**（仅支持 Apple Silicon 与 Intel Mac）
- 网络连接（首次运行需下载 Playwright 浏览器）
- 无需安装 Python 环境（应用已内置自包含 Python 引擎）


## 启动方式

1. 打开 Finder，进入 `xxt-swift/dist/` 目录
2. 双击 `XxtApp.app`（显示名为「学习通作业爬取工具」）
3. 首次打开若提示“无法打开”，请右键图标 → 选择“打开”
4. 建议将 `.app` 拖到 Dock 或 `/Applications` 方便下次使用

> **注意**：应用已内置自包含 Python / Playwright 引擎，双击启动时无需额外配置 Python 环境或 PATH。

如果系统反复提示权限，请前往：

> 系统设置 → 隐私与安全性 → 完全磁盘访问权限 → 添加 `XxtApp.app`

如果双击 `.app` 没有反应，可查看引擎日志排查：

```bash
open "$HOME/Library/Application Support/XxtApp/logs"
```

## 使用方法

### 应该使用哪个 URL？

请使用**课程主页面**的 URL，也就是左侧导航栏能看到「作业」标签、右侧显示作业列表的那个页面。

正确的 URL 特征：

- 地址栏以 `https://mooc2-ans.chaoxing.com/mooc2-ans/mycourse/stu` 开头
- 页面左侧有「作业」「考试」「任务」「章节」等导航
- 右侧显示「查找」「排序」「树和二叉树」等作业条目，每个条目旁有「智能分析」链接

示例：

```
https://mooc2-ans.chaoxing.com/mooc2-ans/mycourse/stu?courseid=227585980&clazzid=139453928&cpi=434723739&enc=...&t=...
```

**不要使用的 URL**：

| 错误类型 | 示例 | 原因 |
| --- | --- | --- |
| 单个作业/测验页面 | 地址含 `work/view`、`exam/view` | 工具会自动进入每个作业，无需手动提供 |
| 智能分析页面 | 地址含 `analysis`、`analyse` 或页面标题含「智能分析」 | 该页面只有题型统计，没有题目内容 |
| 登录页 | 地址含 `login` | 请先登录后再复制课程页 URL |

### 操作步骤

1. **选择课程**：点击流程卡片上的「选择课程」下拉菜单，从账号课程列表选中要抓取的课程。若下拉加载不到，可展开「课程 URL」输入框粘贴课程主页链接兜底
2. **设置输出目录**（可选）：在「设置…」（`⌘,`）中指定结果保存位置，默认 `~/Desktop/out`
3. （可选）在「设置…」中开启「保存后自动导出 PDF」等选项
4. 点击课程后自动加载作业列表，勾选要抓取的作业（默认全部）
5. 点击 **开始抓取**
6. 若未登录，会自动弹出登录界面让你用学习通 App 扫码
7. 登录成功后状态会保存，后续运行无需重复登录；**已登录时打开应用会自动在后台加载课程列表**
8. 抓取过程中仍可继续勾选新增作业，**自动追加进当前抓取队列**
9. 抓取完成后，点击 **打开输出目录** 查看 Word、PDF、图片等结果

### 其他按钮 / 常用功能

- **待修复（批量修复）**：在「待修复」页检测答案缺失的历史作业并一键「扫描 / 修复选中」
- **打开输出目录**：在 Finder 中打开本次结果目录
- **清空日志**：清空界面保存的运行日志
- **导出 PDF**：通过设置开关「保存后自动导出 PDF」自动完成，无需手动操作
- **合并文档**：本次所有作业自动合并为一个 Word，无需手动合并

### 外观与界面

在「设置…」（`⌘,`）中可设置：

- **外观**：跟随系统（默认）/ 浅色 / 深色，切换即时生效（无需重启）
- **界面风格**：焕新界面（默认，单页任务流）/ 经典界面（侧栏 + 分栏详情），可在工具栏一键切换

选择会保存到 `settings.json` 的 `appearance` 字段。

## 输出文件说明

默认输出到 `~/Desktop/out`（可在设置中修改），结构如下：

| 路径/文件 | 说明 |
| --- | --- |
| `~/Desktop/out/课程名称_YYYYMMDD_HHMMSS/` | 每次抓取的结果目录，以「课程名称_时间戳」命名 |
| `…/课程名称_YYYYMMDD_HHMMSS/作业标题.docx` | 单个作业的 Word 文档 |
| `…/课程名称_YYYYMMDD_HHMMSS/全部作业合并.docx` | 本次所有作业合并后的 Word 文档 |
| `…/课程名称_YYYYMMDD_HHMMSS/images/` | 作业中下载的图片 |
| `…/课程名称_YYYYMMDD_HHMMSS/.metadata/` | 原始 JSON 元数据（隐藏目录） |
| `~/Desktop/out/debug/课程名称_YYYYMMDD_HHMMSS/` | 调试用截图与 HTML |

引擎运行数据（**与应用安装目录隔离，不随项目根目录**）存于 `~/Library/Application Support/XxtApp/`：

| 文件 | 说明 |
| --- | --- |
| `settings.json` | 用户配置（输出目录、外观、窗口状态等） |
| `state.json` | 登录状态，复用可免登录 |
| `progress.json` | 作业抓取进度记录（用于断点续传） |
| `cookies.txt` | 可选：放置手动复制的 Cookie |
| `logs/` | 分级轮转的运行日志 |

---

### 断点续传

程序会自动生成 `progress.json`，记录每个作业的抓取状态（已完成 / 失败 / 未抓取）。

- **自动跳过已完成**：点击"开始抓取"时，会自动跳过 `progress.json` 中标记为"已完成"的作业，只抓取未抓取或失败的作业。
- **失败重试**：上次运行中失败的作业会被标记为"失败"，下次运行时会自动重新抓取。
- **强制重新抓取**：如需从头抓取全部作业，可勾选「设置」中的「强制重新抓取已完成」，或删除 `~/Library/Application Support/XxtApp/progress.json`。

### 选择性抓取

如果你只想抓取部分作业：

1. 在主界面上方输入课程 URL，点击「加载」获取作业列表
2. 列表会显示每个作业的抓取状态（已完成 / 失败 / 未抓取）
3. 按需勾选想抓取的作业，可用「全选 / 清空」快速调整（默认全选）
4. 点击「开始抓取」即可只抓取勾选项

## 常见问题

### Q1：点击 `.app` 没有反应？

- 检查 `launcher.log` 中的错误；确认已允许「完全磁盘访问权限」

### Q2：每次运行都提示权限？

- 在"系统设置 → 隐私与安全性 → 完全磁盘访问权限"中添加本应用

### Q3：抓取的作业答案为空？

部分作业在学习通页面本身不显示标准答案，只能抓取到学生答案或空值。可尝试：

1. 使用“批量修复作业”功能重新抓取
2. 检查浏览器中该作业是否确实展示了正确答案

### Q4：Word 中的图片显示不全？

工具已根据图片原始尺寸自动缩放。若仍有问题，可手动在 Word 中调整图片大小，或检查是否缺少 `Pillow` 依赖。

### Q5：导出 PDF 失败？

PDF 导出需要以下任一环境：

- Microsoft Word（macOS）+ `docx2pdf`
- LibreOffice（命令行 `soffice` 可用）

### Q6：Word 中某些图片显示为 `[图片: ...]` 或红叉？

通常是作业标题含 `()`、`[]` 导致旧版路径解析出错。请更新到 v1.1 后重新抓取；已生成的异常文档无需重跑，新抓取的作业会自动使用安全化目录名。

## 注意事项

- 学习通链接中的 `enc`、`t` 等参数时效性较短，若提示登录失效请重新扫码登录
- 抓取速度过快可能导致账号风控，建议保持默认间隔
- 本工具不会上传任何数据，所有文件均保存在本地
- 请勿将 `state.json` 分享给他人，其中包含你的登录凭据
