# 学习通作业抓取工具

> **⚠️ 仅支持 macOS**：本工具为 **macOS 原生应用**（SwiftUI），仅适配 macOS，不提供 Windows / Linux 版本。

一个 macOS 原生（SwiftUI）图形化工具，用于批量抓取学习通（超星）课程作业的题目、选项与答案，并导出为 Word / PDF 文档。

> **声明**：本工具仅供个人备份已购买的课程内容使用，请勿用于侵犯他人权益或违反平台规则的用途。

---

## 功能特性

- 图形界面操作，无需记忆命令行
- 自动登录态持久化，一次登录后续复用
- 自动进入课程作业列表，批量抓取每个作业
- 自动过滤“智能分析”页面，避免误入统计页
- 支持题目分页、逐题翻页
- 支持文字、图片题干与选项
- 图片自动下载到本地并嵌入 Word
- 自动合并本次所有作业为一个 Word 文档
- 可选自动导出 PDF
- 支持历史作业批量修复（重新抓取答案缺失的作业）
- macOS 原生界面（SwiftUI），流畅的中文体验

## 系统要求

- **macOS 14.0（Sonoma）或更高版本**（仅支持 Apple Silicon 与 Intel Mac）
- 网络连接（首次运行需下载 Playwright 浏览器）
- 无需安装 Python 环境（应用已内置自包含 Python 引擎）

## 安装步骤

### 1. 下载应用

从 Releases 页面下载「学习通作业抓取工具」`.app`，解压到任意目录，例如：`/Users/你的用户名/Documents/xxt`

### 2. （开发者）从源码运行

若想从源码运行或二次开发，需安装依赖：

```bash
cd /Users/你的用户名/Documents/xxt
pip install -r requirements.txt
```

### 3. 安装 Playwright 浏览器

```bash
playwright install chromium
```

## 启动方式

1. 打开 Finder，进入项目目录
2. 双击 `学习通作业抓取工具.app`
3. 首次打开若提示“无法打开”，请右键图标 → 选择“打开”
4. 建议将 `.app` 拖到 Dock 或 `/Applications` 方便下次使用

> **注意**：应用已内置自包含 Python / Playwright 引擎，双击启动时无需额外配置 Python 环境或 PATH。

如果系统反复提示权限，请前往：

> 系统设置 → 隐私与安全性 → 完全磁盘访问权限 → 添加 `学习通作业抓取工具.app`

如果双击 `.app` 没有反应，可查看启动日志排查：

```bash
open "$HOME/Library/Logs/学习通作业抓取工具/launcher.log"
```

## 使用方法

### 应该使用哪个 URL？

请使用**课程主页面**的 URL，也就是左侧导航栏能看到「作业」标签、右侧显示作业列表的那个页面。

正确的 URL 特征：

- 地址栏以 `https://mooc2-ans.chaoxing.com/mooc2-ans/mycourse/stu` 开头
- 页面左侧有「作业」「考试」「任务」「章节」等导航
- 右侧显示「查找」「排序」「树和二叉树」等作业条目，每个条目旁有「智能分析」链接

示例：

```
https://mooc2-ans.chaoxing.com/mooc2-ans/mycourse/stu?courseid=227585980&clazzid=139453928&cpi=434723739&enc=...&t=...
```

**不要使用的 URL**：

| 错误类型 | 示例 | 原因 |
| --- | --- | --- |
| 单个作业/测验页面 | 地址含 `work/view`、`exam/view` | 工具会自动进入每个作业，无需手动提供 |
| 智能分析页面 | 地址含 `analysis`、`analyse` 或页面标题含「智能分析」 | 该页面只有题型统计，没有题目内容 |
| 登录页 | 地址含 `login` | 请先登录后再复制课程页 URL |

### 操作步骤

1. **配置课程 URL**：把上述课程主页面的地址粘贴到「课程 URL」输入框
2. **选择输出目录**：点击「选择…」按钮，指定结果保存位置
3. **（可选）显示浏览器**：勾选后启动浏览器窗口，便于调试
4. **（可选）自动导出 PDF**：勾选后每保存一个 Word 会自动生成 PDF
5. 点击 **开始抓取**
6. 若未登录，会自动打开浏览器让你扫码或账号登录
7. 登录成功后状态会保存到 `state.json`，后续运行无需重复登录
8. 抓取完成后，点击 **打开输出目录** 查看 Word、PDF、图片等结果

### 其他按钮

- **批量修复作业**：重新抓取历史结果中答案缺失的作业
- **导出 PDF**：把当前输出目录下所有 Word 转成 PDF
- **合并文档**：把本次所有 Word 作业合并成一个文档
- **打开输出目录**：在 Finder 中打开结果目录
- **清空日志**：清空界面下方的运行日志

### 外观设置

界面左侧「外观」下拉框可选择界面主题：

- **跟随系统**（默认）：自动匹配 macOS 浅色 / 深色模式，切换系统外观时重启应用后生效
- **浅色**：始终使用浅色主题
- **深色**：始终使用深色主题

切换外观会即时生效（无需重启）。选择会保存到 `settings.json` 的 `appearance` 字段。

## 输出文件说明

项目目录下会生成以下文件/目录：

| 路径/文件 | 说明 |
| --- | --- |
| `out/课程名称_YYYYMMDD_HHMMSS/` | 每次抓取的结果目录，以「课程名称_时间戳」命名 |
| `out/课程名称_YYYYMMDD_HHMMSS/作业标题.docx` | 单个作业的 Word 文档 |
| `out/课程名称_YYYYMMDD_HHMMSS/全部作业合并.docx` | 本次所有作业合并后的 Word 文档 |
| `out/课程名称_YYYYMMDD_HHMMSS/images/` | 作业中下载的图片 |
| `out/课程名称_YYYYMMDD_HHMMSS/.metadata/` | 原始 JSON 元数据（隐藏目录） |
| `debug/课程名称_YYYYMMDD_HHMMSS/` | 调试用截图与 HTML |
| `state.json` | 登录状态，复用可免登录 |
| `settings.json` | 用户配置（输出目录、外观、窗口状态等） |
| `cookies.txt` | 可选：放置手动复制的 Cookie |
| `progress.json` | 作业抓取进度记录（用于断点续传） |

---

### 断点续传

程序会自动在项目根目录生成 `progress.json`，记录每个作业的抓取状态（已完成 / 失败 / 未抓取）。

- **自动跳过已完成**：点击"开始抓取"时，会自动跳过 `progress.json` 中标记为"已完成"的作业，只抓取未抓取或失败的作业。
- **失败重试**：上次运行中失败的作业会被标记为"失败"，下次运行时会自动重新抓取。
- **强制重新抓取**：如需从头抓取全部作业，可勾选 GUI 中的「强制重新抓取」，或手动删除 `progress.json`。

### 选择性抓取

如果你只想抓取部分作业：

1. 在 GUI 中输入课程 URL
2. 点击"选择作业并抓取"
3. 程序会加载课程作业列表，并弹出选择对话框
4. 对话框中会显示每个作业的当前状态（已完成 / 失败 / 未抓取）
5. 勾选想抓取的作业，支持"全选 / 反选 / 仅未抓取 / 清除选择"，也可以勾选"跳过已完成的作业"
6. 点击"开始抓取选中项"即可

## 常见问题

### Q1：点击 `.app` 没有反应？

- 检查 `launcher.log` 中的错误；确认已允许「完全磁盘访问权限」

### Q2：每次运行都提示权限？

- 在"系统设置 → 隐私与安全性 → 完全磁盘访问权限"中添加本应用

### Q3：抓取的作业答案为空？

部分作业在学习通页面本身不显示标准答案，只能抓取到学生答案或空值。可尝试：

1. 使用“批量修复作业”功能重新抓取
2. 检查浏览器中该作业是否确实展示了正确答案

### Q4：Word 中的图片显示不全？

工具已根据图片原始尺寸自动缩放。若仍有问题，可手动在 Word 中调整图片大小，或检查是否缺少 `Pillow` 依赖。

### Q5：导出 PDF 失败？

PDF 导出需要以下任一环境：

- Microsoft Word（macOS）+ `docx2pdf`
- LibreOffice（命令行 `soffice` 可用）

### Q6：Word 中某些图片显示为 `[图片: ...]` 或红叉？

通常是作业标题含 `()`、`[]` 导致旧版路径解析出错。请更新到 v1.1 后重新抓取；已生成的异常文档无需重跑，新抓取的作业会自动使用安全化目录名。

## 注意事项

- 学习通链接中的 `enc`、`t` 等参数时效性较短，若提示登录失效请重新扫码登录
- 抓取速度过快可能导致账号风控，建议保持默认间隔
- 本工具不会上传任何数据，所有文件均保存在本地
- 请勿将 `state.json` 分享给他人，其中包含你的登录凭据
